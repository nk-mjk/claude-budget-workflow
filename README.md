# budget-workflow

**Claude Cowork 가성비 워크플로우 스킬**  
비싼 모델은 생각에만, 실행은 저렴한 모델에게.

> 제작: 조남경 (Blue) × Claude | 버전: 1.0.0

<img src='./blob/main/budget-workflow.png' width='75%' align=center>

---

## 이 스킬이 하는 일

Claude Cowork에서 큰 작업을 할 때, 모든 단계를 Fable 하나에 맡기면 비용이 크게 나온다. 단순 반복 실행까지 최고급 모델이 처리하기 때문이다.

**budget-workflow**는 작업을 역할에 따라 4단계로 나누고, 각 단계를 적합한 모델 세션에서 실행하게 안내하는 반자동 파이프라인이다.

```
Sonnet (전처리) → Fable (기획) → Opus / Sonnet (실행) → Fable (합산·검증)
```

세션 간 상태는 작업 폴더의 `진도표.md` 하나가 단일 출처로 관리한다.  
사람이 직접 각 단계를 확인하고 다음 세션을 열기 때문에, 작업 흐름이 항상 투명하게 보인다.

---

## 설치 방법

### 방법 1 — .skill 파일로 설치 (권장)

1. 이 레포에서 `budget-workflow.skill` 파일을 다운로드한다.
2. Claude Cowork → Settings → Customize → 스킬 → [+](스킬추가) → 스킬만들기 → 스킬 업로드  에서 파일을 드래그하거나 설치한다.

### 방법 2 — 폴더를 직접 복사

`budget-workflow/` 폴더 전체를 Cowork 스킬 디렉토리에 복사한다.

---

## 사용 방법

### 시작

Cowork에서 **Sonnet** 모델을 선택해 새 대화를 시작한 뒤, 작업 폴더를 선택하고 말한다.

```
가성비 워크플로우 시작
```

또는 스킬을 직접 호출한다.

```
/budget-workflow
```

### 5단계 흐름

| 단계 | 모델 | 하는 일 | 산출물 |
|------|------|---------|--------|
| 1단계 | Sonnet | 아이디어 → 요구서 작성 | `요구서.md` |
| 2단계 | Fable | 작업 쪼개기 → 지시서 생성 | `지시서-[번호]-[내용]-[모델].md` |
| 3단계 | Opus / Sonnet | 지시서 실행 → 결과물 저장 | `결과물-[번호]-[내용].md` |
| 4단계 | Fable | 합산·검증 → 최종본 또는 재작업 지시 | 최종본 |
| 5단계 | — | 완성된 결과물 취합·납품 | — |

### 세션 이동

각 단계가 끝나면 새 Cowork 세션을 열고 **같은 작업 폴더**를 선택한다.  
스킬이 `진도표.md`를 읽고 다음 단계를 자동으로 파악한다.

## 폴더 구조

```
budget-workflow/
├── SKILL.md                  # 스킬 본체 — 진입점·라우팅·공통 규칙
├── reference/
│   ├── stage1-intake.md      # 1단계 상세 가이드
│   ├── stage2-planning.md    # 2단계 상세 가이드
│   ├── stage3-execution.md   # 3단계 상세 가이드
│   ├── stage4-review.md      # 4단계 상세 가이드
│   └── gotchas.md            # 이상 상황 대응 (이상 시에만 로드)
└── templates/
    ├── progress-board.md     # 진도표 템플릿
    ├── requirements.md       # 요구서 템플릿
    └── work-order.md         # 지시서 템플릿
```

## 언제 쓰면 좋은가

- Cowork를 어느 정도 써본 **중급 이상** 사용자
- Fable의 성능이 필요하지만 **비용 부담**을 느끼는 경우
- 단일 세션으로 감당하기 어려운 **대규모 작업**

단순한 짧은 작업에는 오버스펙이다. 세션을 여러 번 열고 파일을 관리하는 수고가 들어가는 만큼, 그 수고를 보상하는 규모의 작업에 써야 한다.
